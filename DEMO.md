# Shibuya Kart — demo notes

- **Live URL:** not deployed yet — run locally: `npm ci && npm run build && npm start` → http://localhost:8080 (opens on Shibuya Scramble Crossing). Deploy with the existing `Dockerfile` (Node 19, serves `build/` via http-server on port 8080).
- **Controls:** W/S or ↑/↓ accelerate/brake, A/D or ←/→ steer, hold Space while turning to drift and release for a boost, R restart, M engine sound, C toggles back to the normal streets.gl orbit camera. Hold accelerate on "1" for a rocket start; on "3" or "2" it's a jump start.
- **What works:** 3-2-1-GO countdown with intro camera pan, drivable kart with chase camera on real 3D Shibuya, building collisions, 3 glowing Stars collected in course order (Scramble Crossing → 109 → Miyashita Park, about a one-minute run) with a light beam and screen-edge arrow on the next one, Mario Kart style timer with split times, finish screen with best time (saved locally), synthesized sounds (beeps, chime, boost, fanfare, optional engine hum), drift + boost with glow feedback on the kart model.
- **What's stubbed:** the kart is a procedural low-poly model (no imported asset), Stars are not snapped to roads, elevated structures (bridges, overhangs) also block the kart.
- **How streets.gl was extended:** a new `KartControlsNavigator` plugs into the existing `ControlsSystem`, a `KartSystem` adds a procedurally built `KartModel` (chassis, driver, steering/rolling wheels, boost flames, drift sparks) and `ColoredBox` stars to the existing scene graph, and a 30-line `renderKart()` in `GBufferPass` draws them with a new flat-shaded vertex-color material whose glow output feeds the existing bloom pass — everything else is untouched upstream streets.gl.
